# Breakdown Analysis: Core Results

This note summarizes the split-level breakdowns generated by `scripts/breakdown_analysis.py` and saved under `outputs/breakdown_analysis/`.

## 1. IID Test Performance Is Strongest On Template Rows

On `test.csv`, all learned models perform better on `template` rows than on `real` rows:

- DeBERTa-v3: real-source F1 `0.9827` vs template-source F1 `0.9988`
- DistilBERT: real-source F1 `0.9723` vs template-source F1 `0.9975`
- TF-IDF + LR: real-source F1 `0.9497` vs template-source F1 `0.9956`

This means the aggregate IID headline metric is partly supported by easier template-heavy slices.

## 2. Several Attack Types Are Overwhelmingly Template-Driven

Attack-type composition on `test.csv` is uneven:

- `tool_injection`: `3` real / `149` template (`0.020` real share)
- `encoded_attack`: `6` real / `139` template (`0.041` real share)
- `contextual_manipulation`: `54` real / `363` template (`0.129` real share)
- `data_exfiltration`: `78` real / `150` template (`0.342` real share)
- `direct_override`: `747` real / `0` template
- `roleplay_attack`: `381` real / `0` template

This matters when interpreting near-perfect subtype recall: some of the easiest-looking subtype results come from heavily templated attack slices.

## 3. Domain OOD Is Heterogeneous, Not Uniformly Strong

The weakest learned-model domain is `code`:

- DeBERTa-v3 on `code`: F1 `0.9439`, benign FPR `0.0160`, attack recall `0.9080`
- DistilBERT on `code`: F1 `0.6070`, benign FPR `0.0280`, attack recall `0.4480`

DistilBERT remains strong on `medical`, `finance`, and `legal`, so the domain-OOD story is not simple overall degradation. It is heterogeneous degradation with one especially weak domain.

TF-IDF + LR shows a different failure pattern: its weakest domain is `legal` with F1 `0.8721`, driven by benign FPR `0.2520` rather than low recall.

## 4. Structural OOD Failure Concentrates By Transform

Structural OOD is not a uniform shift. Failure depends heavily on the transform:

- DeBERTa-v3:
  - `instruction_prefix_mimic`: benign FPR `0.8468`, attack recall `1.0000`
  - `prompt_dilute`: benign FPR `0.8348`, attack recall `0.9760`
  - `json_wrap`: benign FPR `0.7928`, attack recall `0.9940`

- DistilBERT:
  - `instruction_prefix_mimic`: benign FPR `0.9820`, attack recall `0.9940`
  - `prompt_dilute`: benign FPR `0.8228`, attack recall `0.8649`
  - `json_wrap`: benign FPR `0.3904`, attack recall `0.4324`

- TF-IDF + LR:
  - `prompt_dilute`: benign FPR `0.8408`, attack recall `0.9249`
  - `instruction_prefix_mimic`: benign FPR `0.7748`, attack recall `0.9550`
  - `json_wrap`: benign FPR `0.7598`, attack recall `0.9459`

The most important lesson is that structural OOD failure is not a single phenomenon. Some transforms mainly cause over-defense (`instruction_prefix_mimic`), while others can also suppress attack recall (`json_wrap` for DistilBERT).

## 5. Obfuscation Robustness Is Good Within This Construction, But Not Uniform

The learned models remain strong on the frozen obfuscation slice, but the hardest obfuscation is consistently `rot13_wrap`:

- DeBERTa-v3: `0.9737` recall on `rot13_wrap`
- DistilBERT: `0.9211` recall on `rot13_wrap`
- TF-IDF + LR: `0.7895` recall on `rot13_wrap`

The strongest obfuscation numbers are therefore encouraging within this benchmark construction, but they should not be described as solved or uniform across transforms.

## Reviewer-Facing Lesson

The breakdowns add three paper-relevant lessons beyond the aggregate tables:

1. High IID F1 is partly supported by easier template-heavy slices.
2. Aggregate OOD numbers can hide domain-specific or transform-specific collapse.
3. Structural OOD failure is not only "OOD is hard"; it is a mix of benign false positives and transform-specific recall failure.
